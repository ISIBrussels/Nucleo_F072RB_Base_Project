# Nucleo F072RB - Projet de Démarrage

Projet créé avec STM32CubeIDE version 1.19.0 et testé en novembre 2026.

Ce projet de base peut être importé dans STM32CubeIDE (version 1.x.y, pas la version 2) et est prêt à utiliser.
La seule fonctionnalité implémentée dans `main(...)` est une clignotement de la LED verte `LD2`.

Pour importer ce projet, depuis Eclipse (depuis un nouveau Workspace pour éviter les conflits de nom de projet) :
```
File -> Import -> General -> Existing Project into Workspace 
```
